# slp harness · папка компании

Кит и симулятор к классу SLP'26 «AI for Business», 14 октября 2026. Пример – вымышленный банный комплекс «Лунная каменка» в Москве на 18 человек: будни пустые, отзывы без ответа, договорённости живут в WhatsApp администратора. За одиннадцать фаз пустая папка становится системой, которую читают люди и агенты.

**Симулятор:** https://slp-ai-business.lab.aimindset.org/sim/
**Папка компании целиком, с картинками и переходами между файлами:** [kit/files/](kit/files/)
**Презентация класса:** https://slp-ai-business.lab.aimindset.org/deck/

## шестнадцать разделов, три уровня

У каждого раздела своя метафора из камня каменки, описание и три запроса агенту от простого к сложному. Остановиться можно после любого уровня.

| уровень | разделы | что получаете | время |
|---|---|---|---|
| **1 · база** | [паспорт](kit/files/company/) · [сырьё](kit/files/sources/) · [встречи](kit/files/meetings/) · [вопросы](kit/files/asks/) | память компании: паспорт из анкеты, имена файлов, транскрипты, первый вопрос к папке | вечер |
| **2 · правила и карточки** | [правила](kit/files/rules/) · [роли](kit/files/people/) · [гости](kit/files/audience/) · [конкуренты](kit/files/competitors/) · [каналы](kit/files/channels/) · [инструменты](kit/files/tools/) · [развернуть у себя](kit/files/guides/) | агенту можно задавать вопросы вместо коллег: кто решает, по какому правилу, что на рынке | неделя по часу |
| **3 · агенты** | [задачи](kit/files/tasks/) · [проверки](kit/files/checks/) · [рутины](kit/files/routines/) · [срезы](kit/files/dashboards/) · [счёт часов](kit/files/metrics/) | задачи после встреч ставятся сами, рынок – по понедельникам, срезы на одном экране | настройка 6 часов |

Один вопрос «что мы обещали корпоративному клиенту?» проходит все три уровня: сначала агент отвечает по транскрипту, потом называет роль и правило, потом показывает задачи со статусом и проверяет слова клиента по рынку.

## своя компания

**Без терминала:** в симуляторе кнопка «свой бизнес» → тип бизнеса или своя анкета → запросы агенту по всем разделам под вашу компанию и стартовая папка архивом. Ответы остаются в браузере.

**С терминалом:**
```bash
git clone https://github.com/ai-mindset-org/slp-harness.git ~/slp-harness
~/slp-harness/bin/new.sh ~/harness/lunnaya-kamenka     # образец целиком: коммит на фазу, граф в браузере
cd ~/harness/lunnaya-kamenka && claude                  # агент сам читает AGENTS.md и CLAUDE.md
```
Или двойной клик по `! Open SLP Harness.command`. Нужны git и Node.js 18+. Папка открывается в Obsidian как хранилище, ссылки между файлами – обычные markdown: работают на GitHub, в Obsidian и у агентов.

## слой SLP-контекста

Второй слой – папка курса: классы, треки, гости-спикеры, кластеры участников по бэкграунду. Граф открывает её так же, как папку компании: кнопка «выбрать папку» в режиме Local или `bin/open.sh <папка курса>`. Карточки размечены полем `type`: `class` · `track` · `guest` · `person` · `cluster`. В этот репозиторий папка курса не входит: она хранится только на компьютере ведущего.

## устройство

```
kit/
  answers.json        ответы анкеты: подставляются в {{company}} и другие поля
  manifest.json       11 фаз с полями level · ask · halt · stop, 4 дорожки агентов
  files/              папка компании в финальном виде; README в каждом разделе
  files/_assets/      метафоры разделов и превью конкурентов
  versions/           промежуточные версии: AGENTS.md v1–v2, ответ на вопрос v1–v2
tools/                timeline · build-scenario · export-tools · harness-server · harness-demo
web/                  симулятор: index.html · app.js · setup.js · styles.css · sections.json · tools/
bin/                  new.sh · open.sh · fork.sh · replay.sh · stop.sh
```

Правка кита: файл в `kit/files/` или фаза в `kit/manifest.json` → `node tools/build-scenario.mjs`.
