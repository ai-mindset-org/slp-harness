    01 · папка в браузере

    выбери папку харнесса на компьютере или перетащи её сюда из Finder. граф строится из файлов, правки сохраняются прямо в них. без установки; агенты, сессии, откат и коммиты – в полном режиме. на телефоне папку не выбрать: подключай с компьютера.

    02 · полный режим: агенты, сессии, откат, форк, Obsidian

    в терминале: скачать движок в новую папку (нужны git и Node.js 18+):

    git clone https://github.com/ai-mindset-org/slp-harness.git ~/slp-harness

    создать свою папку из кита банного комплекса и открыть граф. Существующую папку new.sh не перезаписывает:

    ~/slp-harness/bin/new.sh ~/harness/my-company
    открыть localhost:4747 ↗если граф уже запущен; при занятом 4747 open.sh берёт следующий порт и пишет адрес в терминале

    свой харнесс с нуля: ~/slp-harness/bin/new.sh ~/harness/my-company · копия с историей: ~/harness-engine/bin/fork.sh ~/harness/my-product ~/harness/my-try · остановить: ~/harness-engine/bin/stop.sh [порт] · нет gh: brew install gh && gh auth login

      папка компании: банный комплекс в Москве
      
    
      вымышленный банный комплекс на 18 человек: будни пустые, отзывы без ответа, договорённости в WhatsApp администратора. за десять шагов пустая папка становится системой. уровень 1 – база: паспорт, имена, встречи. уровень 2 – правила, роли, гости, реальные конкуренты Москвы через Exa, каналы из класса про маркетинг. уровень 3 – агенты ставят задачи и сами смотрят конкурентов. остановиться можно после любого уровня.
