Загрузка: где пусто

Занятые слоты по дням и часам: чем темнее, тем полнее. Красная рамка – слот загружен меньше чем на 40%. Будни до 17:00 – главная дыра; суббота +43%, воскресенье +48% к будню по данным банка.

выходные–средняя загрузка
недобор за неделю–зал на шестерых: пустые часы × цена по правилу
слотов меньше 40%–из 28 в неделе

методика В какие дни и слоты бани стоят пустыми и где можно поднять цену или запустить акцию?
источники
  • Своя система записи (YCLIENTS/Altegio) – фактические брони по своим номерам: основа точной загрузки
  • Виджеты бронирования конкурентов – видимые свободные слоты на 7 дней, где виджет открыт без входа
  • Яндекс Карты «популярное время» – график загруженности по часам, если показан для организации
  • Google Maps «Popular times» – график по дням недели, относительная шкала
как собирается
Для своей бани агент ежедневно в 06:00 читает брони за прошлые сутки и следующие 14 дней из YCLIENTS по API и делит на четыре слота (9–13, 13–17, 17–21, 21–01). Для конкурентов раз в неделю снимает видимые слоты браузером (Playwright) там, где виджет открыт; иначе берёт график популярного времени.
поля
date, weekday, slot, rooms_total, rooms_free, occupancy_pct, source, observed_at
как считается
Загрузка слота = (занято номеро-слотов / всего номеро-слотов) × 100; будни и выходные усредняются по дням; прокси конкурентов = доля занятых видимых слотов в окне 7 дней.
где ошибается
  • Видимые слоты конкурента не равны брони: часть номеров закрыта вручную
  • Окно 7 дней показывает предварительную запись, а не итоговую загрузку
  • Популярное время даёт относительную шкалу, а не проценты
  • Выборка конкурентов мала: открытых виджетов единицы
рутина
Ежедневная автоматизация 06:00 на VM105 по своим броням; еженедельная в воскресенье 20:00 по конкурентам; один владелец расписания, receipt в журнал.
чего не берём
ПДн: имена и телефоны в брони, состав компании, номера карт. Из брони берутся только дата, слот, номер и факт занятости.
что улучшить
Добавить строку «потерянная выручка пустых слотов» = пустые номеро-слоты × средняя цена слота, чтобы пустота читалась в рублях за неделю.
