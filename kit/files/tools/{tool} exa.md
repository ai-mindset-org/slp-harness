# Exa MCP

Поиск по вебу для агента: возвращает страницы с текстом, датой и ссылкой. Агент пишет карточку и рядом источник.

## подключить
- Claude Code: `claude mcp add --transport http exa https://mcp.exa.ai/mcp`
- в папке уже лежит `.mcp.json` с тем же адресом; ключ, если нужен, – в переменной окружения `EXA_API_KEY`, в файлы его не кладём

## как спрашивать
Конкретно: город, формат, что нужно вытащить, свежесть. Пример запросов – в [кто конкуренты рядом](<../asks/{ask} кто конкуренты рядом.md>).
