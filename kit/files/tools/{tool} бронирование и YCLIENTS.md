# Бронирование

Брони – главный источник цифр загрузки: [брони – сентябрь 2026](<../sources/{source} брони – сентябрь 2026.md>). Агенту нужна выгрузка по слотам без имён гостей ([данные и ИИ](<../rules/{rule} данные и ИИ.md>)).

| система | что умеет | цена в месяц | источник |
|---|---|---|---|
| YCLIENTS | универсальный журнал записи; есть официальная инструкция 'Бани и банные комплексы': услуга = длительность аренды, 'сотрудник' = парная | от 960 (страница для спа); для сауны с 2 парными, виджетом, SMS и депозитом оценка практика 2 500-4 500; другой автор: старт от 1 500, средний объект 3 500-6 000 | [support.yclients.com](https://support.yclients.com/5-31-603--vnedrenie-nastrojki-zhurnala-zapisi-dlya-bani/) |
| Bnovo (PMS + 'Часовые услуги' для бань, беседок, спа) | баня как допуслуга загородного объекта или мини-отеля; слоты по часам, календарь заказов с февраля 2026 | Старт 300 за номер (минимум 3 900 в месяц), Рост 400 (минимум 6 500, есть динамика цен и часовые услуги), Максимум 450 + 1% с модуля (минимум 8 500, открытый двусторонний API); указаны цены при оплате за 3 месяца, со скидкой при годовой оплате до 20% | [bnovo.ru](https://bnovo.ru/tarif/) |
| Restoplace | бронирование бань и саун по часам, депозиты за час или за гостя, виджет | есть полноценный бесплатный тариф 'Фри'; платные тарифы: не найдено в выдаче | [restoplace.cc](https://restoplace.cc/servis-dlya-bani) |
| КВИКБИ (KWIKBI) | отраслевая CRM для бань: почасовая аренда, буферы на уборку, тарифная сетка по дням, сбор отзывов на геосервисах, депозит через ЮКассу | бесплатно (1 исполнитель); Бизнес 180; Премиум 250 со сборщиком отзывов | [kwikbi.ru](https://kwikbi.ru/programma-dlya-bani) |
| ReMarked (CRM для общественных заведений) | бронирование бань и саун, приложение, депозиты | по запросу после презентации | [remarked.ru](https://remarked.ru/booking-for-banya-sauna) |
| Tilda + виджет YCLIENTS | запись на сайт без разработки (блок T790) | стоимость Tilda не искали | [help-ru.tilda.cc](https://help-ru.tilda.cc/online-booking) |
| Reservio (чешский сервис) | запись и POS для спа | бесплатный тариф; оплата и работа из РФ не проверялись | [reservio.com](https://www.reservio.com/ru/softver-dlya-spa) |
| Практики: депозит 30-50% при онлайн-брони | снижает no-show; мнение подрядчика, не исследование: 'депозит 30-50% закрывает 80% no-show'; онлайн-виджет поднимает выручку на 18-32% за 3-6 месяцев на 5 объектах автора |  | [chimitdorzhi.tech](https://chimitdorzhi.tech/blog/avtomatizaciya-saun-ban-spa-2026/) |
