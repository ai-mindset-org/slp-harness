# Транскрибация

Встреча становится файлом в `meetings/`: запись → текст → md с шапкой (дата, роли, без имён гостей) → секретарь выписывает решения.

## старт
Старт за 0 ₽: записать встречу телефоном или Телемостом, прогнать файл через локальный faster-whisper (утилита с папками input и output) на ноутбуке управляющей, результат положить в meetings/ как md. Голосовые из WhatsApp и Telegram экспортируются файлом ogg и идут тем же путём. Секретарь превращает текст в решения. Если ноутбук слабый, SaluteSpeech даёт 100 минут в месяц бесплатно для физлица, а потом около 36 ₽ за час.

## когда вырастет
Взрослая схема: Яндекс SpeechKit или SaluteSpeech по договору юрлица (около 12–48 ₽ за час записи, данные в России), скрипт-приёмник следит за папкой inbox/ и пишет md в meetings/ с шапкой и словарём банных терминов. Плановые встречи идут через Телемост с Алисой Про, если у салона уже Яндекс 360. Зарубежные боты (tl;dv, Krisp) остаются для встреч без данных гостей. Решение по сервису фиксируется файлом в rules/ с запретом отправлять за рубеж записи, где звучат имена и телефоны гостей.
