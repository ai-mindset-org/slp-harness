# Отзывы на картах

Отзывы забирает [отзывы каждое утро](<../routines/{routine} отзывы каждое утро.md>), отвечает администратор по [голос бренда](<../rules/{rule} голос бренда.md>).

| площадка | как достать и ответить | источник |
|---|---|---|
| Яндекс Бизнес (Карты и Поиск) | личный кабинет Яндекс Бизнеса: роль Владелец или Представитель, раздел 'О компании - Отзывы'; уведомления на почту; один официальный ответ, проходит модерацию; видны только последние 600 опубликованных отзывов; удалить отзыв владелец не может, только пожаловаться | [yandex.ru](https://yandex.ru/support/business-priority/ru/manage/reviews) |
| 2ГИС Бизнес | бесплатный личный кабинет account.2gis.com: 'Моя компания - Отзывы', ответ и жалоба; платная надстройка 'Отзывы Про' – единое окно для отзывов со всех площадок | [help.2gis.ru](https://help.2gis.ru/question/kak-rabotat-s-otzyvami-klientov-instrukciya-dlya-kompaniy) |
| Агрегаторы и боты | Telegram-бот Review-Monitor-Bot (GitHub): 2ГИС по API, Яндекс парсингом через Selenium, проверка каждые 5 минут, отправка в канал | [github.com](https://github.com/alexunderlag/Review-Monitor-Bot) |
| Что в отзывах о термальных комплексах Москвы (аналитика NF Group, 10 тыс. отзывов 2024-2026) |  | [cre.ru](https://cre.ru/analytics/101401) |
