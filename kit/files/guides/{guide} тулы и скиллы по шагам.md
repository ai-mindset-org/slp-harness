## скилл как исполняемый продукт
1. **вызов по имени.** Человек пишет «запусти slot-price на пятницу 24-го» или агент сам видит совпадение с описанием.
2. **агент читает SKILL.md целиком.** До этого в контексте лежали только имя и описание – одна строка.
3. **вход.** Скилл говорит, что нужно: дата, файлы, инструмент. Нет входа – агент спрашивает, а не угадывает.
4. **шаги.** Агент идёт по списку шагов и правилам из `rules/`.
5. **выход.** Файл с датой в имени – туда, куда сказано в разделе «что получается». Решение остаётся за человеком.
6. **коммит.** Сессия кончается коммитом в ветке агента, журнал – в `sessions/`.

Скилл живёт в `skills/`, копия для Claude Code – в `.claude/skills/`, для Codex – в `.agents/skills/`. Правят только `skills/`.

## что проверяет doctor
| проверка | что ловит |
|---|---|
| имена | файл назван не по [правилу имён](<../rules/{rule} имена файлов.md>), тип не совпадает с папкой |
| YAML | нет блока `---`, нет `description` или `type`, блок не читается |
| ссылки | ссылка ведёт на файл, которого нет |
| висячие файлы | на файл не ведёт ни одна ссылка – его никто не найдёт |
| цифры без источника | цена, рейтинг, подписчики без страницы и даты |
| приватное | итог `checks/check-git-private.sh`: телефоны, почты, ключи |

Doctor – правило без кода: агент проходит шаги сам и пишет отчёт. Из кода в папке есть только `checks/check-git-private.sh`.
