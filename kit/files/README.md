# {{company}} · папка компании

Банный комплекс в Москве. Здесь лежит то, что раньше жило в голове владельца, в WhatsApp администратора и в таблице броней. Папку читают люди и агенты: Claude Code, Codex, Cursor, любой харнесс, который понимает `AGENTS.md`.

## что где

Тринадцать общих типов: они подходят любой компании и любой группе. Что именно лежит в файле, говорит имя: `{context} конкурент Сандуновские бани.md`, `{context} сегмент пары.md`.

| папка | тип | что внутри | зачем |
|---|---|---|---|
| `context/` | `{context}` | кто мы и что вокруг: паспорт, рынок, конкуренты, сегменты гостей, каналы | агент знает о компании ровно то, что здесь записано |
| `sources/` | `{source}` | сырьё: выгрузка броней, отзывы | у каждой цифры есть откуда она взялась |
| `meetings/` | `{meeting}` | транскрипты планёрок и звонков | договорённости остаются, даже когда человек ушёл |
| `asks/` | `{ask}` | вопросы к папке и ответы агента | ответ со ссылкой можно проверить |
| `rules/` | `{rule}` | правила бизнеса, каждое на одну страницу | агент отвечает по правилу и не обещает лишнего |
| `people/` | `{role}` | роли команды: кто что решает | агент знает, кому ставить задачу и кто принимает работу |
| `tools/` · `.mcp.json` | `{tool}` | чем агент ходит наружу: Exa, бронирование, отзывы | агент ходит наружу только туда, что здесь описано |
| `tasks/` | `{task}` | задачи после встреч: исполнитель, срок, источник | у договорённости есть исполнитель и срок |
| `checks/` | `{check}` | проверки: задачи по правилам, git и приватные данные | ошибку ловят до того, как она дойдёт до гостя |
| `routines/` | `{routine}` | что агенты делают по расписанию | работа идёт по расписанию, без напоминаний |
| `dashboards/` | `{dashboard}` | срезы: карта, прайсинг, гости, загрузка, радар пабликов, счёт часов | видно, что изменилось и сколько часов сэкономлено |
| `guides/` | `{guide}` | как развернуть у себя | образец переносится в свою компанию |
| `skills/` | `SKILL.md` | скиллы: гайд, инструмент и условие запуска для агента | агент берёт навык, только когда он нужен |

## с чего начать

1. Прочитай [AGENTS](AGENTS.md) – правила для агента. Для Claude Code то же самое лежит в `CLAUDE.md`.
2. Паспорт: [паспорт комплекса](<context/{context} паспорт комплекса.md>).
3. Задай папке вопрос «что мы обещали корпоративному клиенту?» – ответ в [что обещали корпоративному клиенту](<asks/{ask} что обещали корпоративному клиенту.md>).

## одна линия, остановиться где угодно

Папка растёт по шагам, каждый опирается на предыдущий. Остановиться можно после любого шага: уже собранное работает само.

- **после встреч** у компании есть память: паспорт, имена по [имена файлов](<rules/{rule} имена файлов.md>), транскрипты. Один вечер.
- **после правил и ролей** агенту можно задавать вопросы вместо коллег: кто решает, по какому правилу. Неделя по часу.
- **после контекста** агент знает рынок: гостей, конкурентов, каналы.
- **после рутин** задачи после встречи ставятся сами, рынок проверяется по понедельникам. Человек подтверждает деньги и обещания гостям.

Перед тем как делиться папкой: `bash checks/check-git-private.sh` – всё ли в git и нет ли телефонов, почт, ключей.
