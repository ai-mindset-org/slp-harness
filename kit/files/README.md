# {{company}} · папка компании

Банный комплекс в Москве. Здесь лежит то, что раньше жило в голове владельца, в WhatsApp администратора и в таблице броней. Папку читают люди и агенты: Claude Code, Codex, Cursor, любой харнесс, который понимает `AGENTS.md`.

## что где

| папка | что внутри | уровень |
|---|---|---|
| `company/` | паспорт комплекса: зоны, цены, загрузка, команда | 1 |
| `sources/` | сырьё: выгрузка броней, отзывы | 1 |
| `meetings/` | транскрипты планёрок и звонков | 1 |
| `asks/` | вопросы к папке и ответы агента | 1–3 |
| `rules/` | правила бизнеса, каждое на одну страницу | 2 |
| `people/` | роли команды: кто за что отвечает | 2 |
| `audience/` | сегменты гостей | 2 |
| `competitors/` | соседи по рынку: цены, рейтинг, каналы, источник | 2 |
| `channels/` | каналы привлечения из класса SLP про маркетинг | 2 |
| `tools/` · `.mcp.json` | поиск через Exa MCP | 2 |
| `tasks/` · `checks/` | задачи после встреч и их проверка | 3 |
| `routines/` | что агенты делают по расписанию | 3 |
| `dashboards/` · `metrics/` | срезы и счёт часов | 3 |

## с чего начать

1. Прочитай [[AGENTS]] – правила для агента. Для Claude Code то же самое лежит в `CLAUDE.md`.
2. Паспорт: [[{company} паспорт комплекса]].
3. Задай папке вопрос «что мы обещали корпоративному клиенту?» – ответ в [[{ask} что обещали корпоративному клиенту]].

## где остановиться

Каждый уровень работает сам по себе.

- **уровень 1 · база.** Одна папка, имена по [[{rule} имена файлов]], транскрипты встреч. Один вечер.
- **уровень 2 · правила и карточки.** Правила бизнеса, роли, гости, конкуренты, каналы. Агенту можно задавать вопросы вместо коллег. Неделя по часу в день.
- **уровень 3 · агенты.** После встречи агенты сами ставят задачи, по понедельникам смотрят конкурентов. Человек проверяет деньги и обещания гостям.
