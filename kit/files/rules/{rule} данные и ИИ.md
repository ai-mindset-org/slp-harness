# Данные и ИИ

| можно | нельзя |
|---|---|
| цены, зоны, расписание | телефоны, имена, почты гостей |
| отзывы без имён авторов | паспортные данные, оплаты |
| сводки броней по слотам | выгрузку CRM целиком |
| транскрипты встреч команды | записи разговоров с гостями без их согласия |

- встречи команды пишем с уведомлением в начале; кто против – встреча без записи
- персональные данные гостей обрабатываются по 152-ФЗ: в модель уходят только обезличенные сводки
- инструменты с серверами в России или с договором обработки данных – для всего, где есть люди
- агент пишет черновики, отправляет человек
