# Данные и ИИ

| можно | нельзя |
|---|---|
| цены, зоны, расписание | телефоны, имена, почты гостей |
| отзывы без имён авторов | паспортные данные, оплаты |
| сводки броней по слотам | выгрузку CRM целиком |
| транскрипты встреч команды | записи разговоров с гостями без их согласия |

- встречи команды пишем с уведомлением в начале; кто против – встреча без записи
- в модель уходят только обезличенные сводки; требования к обработке персональных данных определяются применимым правом и правилами конкретного оператора
- для данных о людях использовать только одобренные оператором инструменты с проверенными условиями обработки, размещения и необходимыми договорными основаниями
- агент пишет черновики, отправляет человек
