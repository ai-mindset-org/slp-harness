# Отзывы каждое утро

1. собрать новые отзывы с карт, без имён авторов
2. черновик ответа по [голос бренда](<../rules/{rule} голос бренда.md>); цена – только из [цены и бронь](<../rules/{rule} цены и бронь.md>)
3. администратор правит и отправляет; агент сам не публикует
4. раз в неделю – темы отзывов в срез [неделя – 2026-10-12](<../dashboards/{dashboard} неделя – 2026-10-12.md>)
