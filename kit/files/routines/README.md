# рутины

что агенты делают сами по расписанию.

## файлы
- [конкуренты по понедельникам](<{routine} конкуренты по понедельникам.md>) – рутина «конкуренты» – по понедельникам Exa обновляет цены и рейтинги соседей
- [напоминание о бронях](<{routine} напоминание о бронях.md>) – рутина «напоминание о бронях» – за сутки и за 3 часа до слота
- [недельный срез](<{routine} недельный срез.md>) – рутина «недельный срез» – воскресенье 20:00, после выгрузки броней
- [отзывы каждое утро](<{routine} отзывы каждое утро.md>) – рутина «отзывы» – каждое утро черновики ответов, отправляет администратор
- [после встречи](<{routine} после встречи.md>) – рутина «после встречи» – транскрипт → решения → задачи → проверка → утренний список
- [проверка перед пушем](<{routine} проверка перед пушем.md>) – рутина «проверка перед пушем» – перед каждым коммитом и пушем
- [сверка задач с правилами](<{routine} сверка задач с правилами.md>) – рутина «сверка задач с правилами» – каждый вечер 19:00 и при создании задачи
- [утренние задачи](<{routine} утренние задачи.md>) – рутина «утренние задачи» – каждый день 08:30 по расписанию

## запросы агенту, от простого к сложному
| сложность | запрос |
|---|---|
| 1 · просто | Какие рутины уже работают? |
| 2 · средне | Опиши рутину «после встречи» по шагам. |
| 3 · сложно | Запускай рутину конкурентов по понедельникам и присылай срез управляющему. |
