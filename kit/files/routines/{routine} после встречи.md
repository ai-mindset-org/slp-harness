# После встречи

1. **секретарь** читает новый файл в `meetings/`, выписывает решения: что, кто, срок
2. **постановщик** делает задачи в `tasks/` с полями `owner`, `due`, `source`; цена и скидка – задача [[{role} управляющий]]
3. **проверяющий** сверяет задачи с [[{rule} цены и бронь]] и [[{rule} голос бренда]], пишет `checks/`
4. утром каждый получает свои задачи на день

Человек тратит 5 минут на проверку вместо часа на конспект.
