# Git и приватные данные

Проверка перед пушем, перед тем как отдать папку подрядчику и раз в неделю рутиной.

**Запуск:** `bash checks/check-git-private.sh` из корня папки. Код выхода 0 – чисто.

## что смотрит
- всё ли закоммичено и что лежит вне git
- есть ли удалённый репозиторий; если в папке лежит `.local-only`, его быть не должно
- телефоны, почты, ключи и токены, номера карт в файлах git
- слова из `.private-words`, если файл есть: имена гостей, фамилии, названия клиентов – по одному на строку

## запрос агенту
«Запусти `bash checks/check-git-private.sh` и разбери отчёт: что закоммитить, что убрать из файлов, что вынести в `.private-words`. Сам ничего не удаляй и не пушь – список и предложение человеку.»

## кто решает
Пушить и удалять – человек: [владелец](<../people/{role} владелец.md>). Правило о данных – [данные и ИИ](<../rules/{rule} данные и ИИ.md>).
