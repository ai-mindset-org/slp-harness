# скиллы

скилл – навык агента одним файлом: когда запускать, как это делает человек, каким инструментом. В начале работы агент видит только имя и описание скилла, а читает его целиком, когда описание совпало с задачей. Так в контексте не лежит лишнего.

## файлы
- [разбор отзывов](<review-replies/SKILL.md>) – черновики ответов на отзывы в голосе бренда: четыре хода ответа и пример, отправляет администратор
- [срез недели](<weekly-slice/SKILL.md>) – загрузка, отзывы, конкуренты и счёт часов одним файлом к планёрке
- [цена слота](<slot-price/SKILL.md>) – сколько брать за конкретный слот: калькулятор прайсинга, разложение цены, решение за управляющим
- [радар пабликов](<publics-radar/SKILL.md>) – где разместиться: площадки через Exa с оценкой 1–5, черновик письма админу

## где их видят агенты
Источник – эта папка `skills/`, её читают люди, GitHub и Obsidian. Claude Code подгружает скиллы из `.claude/skills/`, Codex – из `.agents/skills/`: туда кладётся копия, `cp -R skills/ .claude/skills/`. Правят только `skills/`, копию обновляют следом.

## запросы агенту, от простого к сложному
| сложность | запрос |
|---|---|
| 1 · просто | Какие скиллы есть в папке и когда каждый запускать? |
| 2 · средне | По скиллу review-replies разбери новые отзывы, ничего не отправляй. |
| 3 · сложно | Напиши скилл по образцу review-replies для ответа корпоративному клиенту: гайд, инструмент, условие запуска. |
