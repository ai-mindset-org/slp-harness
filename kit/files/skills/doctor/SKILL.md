# doctor

**Когда запускать:** перед каждым пушем по рутине [проверка перед пушем](<../../routines/{routine} проверка перед пушем.md>), перед тем как отдать папку наружу, по просьбе «проверь папку».

**Как это делает человек:** [проверяющий](<../../people/{role} агент проверяющий.md>) открывает папку и глазами ищет файлы с кривыми именами, битые ссылки и цифры, у которых нет страницы и даты. Скилл делает тот же обход по списку и пишет, где нашёл.

**Инструмент:** файлы папки и [git и приватные данные](<../../checks/{check} git и приватные данные.md>) со скриптом `checks/check-git-private.sh`. Это правило без своего кода: агент проходит шаги сам.

## шаги
1. **имена.** Каждый файл вне `skills/` назван по [имена файлов](<../../rules/{rule} имена файлов.md>): `{тип} описание`, тип совпадает с папкой, дата в конце в виде ГГГГ-ММ-ДД. В имени нет слов «финал», «новый», «копия».
2. **YAML.** У каждого `.md` в начале блок между `---` с полями `description` и `type`; у скилла – `name` и `description`. Блок читается: нет табуляций, двоеточие в значении взято в кавычки.
3. **ссылки.** Каждая ссылка вида `[текст](<путь>)` ведёт на файл, который есть в папке. Ссылки наружу – с `https://`.
4. **висячие файлы.** Файл, на который не ведёт ни одна ссылка из README раздела или соседних файлов, попадает в список «никто не найдёт».
5. **цифры без источника.** Цена, рейтинг, число подписчиков, доля – рядом есть источник и дата. Нет источника – строка в отчёт: такую цифру агент мог додумать (см. [словарь](<../../guides/{guide} словарь терминов.md>), раздел «агенты додумывают»).
6. **приватное.** Запустить `bash checks/check-git-private.sh` и приложить итог: телефоны, почты, ключи.

## что получается
Файл `checks/{check} doctor – ГГГГ-ММ-ДД.md`: пять разделов по шагам, в каждом – файл, строка, что не так, кому чинить. В конце одна строка: «чисто» или «N замечаний».

## чего нельзя
- переименовывать, удалять и править файлы: только отчёт, чинит постановщик через задачу
- считать цифру проверенной, если источник есть, а даты нет
- пропускать шаг, потому что «в прошлый раз было чисто»
